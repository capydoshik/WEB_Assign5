A responsive and interactive Apple-style website built with **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.  
The site features smooth navigation, authentication (login/signup), and external API integration (iTunes API).

## Features

### 🔹 Home Page
- Dynamic Apple-themed interface with smooth animations.
- Integrated **iTunes API** for searching Apple content (apps, music, movies).
- “View” button opens official iTunes pages in a new tab.
- Interactive statistics counters and accordion FAQ.


### 🔹 Authentication System
- **Login** and **Signup** pages use `localStorage` to manage user credentials.
- When logged in, navbar updates dynamically to show **“My Profile”** instead of “Account”.
- Profile page displays user info and includes **Logout** functionality.


### 🔹 Product Pages
- Dedicated pages for:
  - iPhone  
  - MacBook  
  - AirPods  
  - Support  
- Each includes relevant visuals, product details, and responsive layout.
  

### 🔹 Responsive Design
- Fully mobile-friendly using **Bootstrap 5** grid system.
- Sticky header and adaptive navigation for different screen sizes.


## External API Integration

This project uses the **Apple iTunes Search API** to display real Apple media content.


## How to Run the Project

### Option 1: Local Browser

Download or clone this repository.

Unzip the folder if necessary.

Open index.html in your browser.


### Option 2: VS Code (Recommended)

Install Live Server extension in VS Code.

Right-click index.html → “Open with Live Server”.

Browse all pages from the local server (paths load correctly).
